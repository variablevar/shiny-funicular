## The Strategy Architecture

### Layer 1: Regime Classification (The Gate)
Your unwired KMeans classifier (`core/regime_classifier.py`) finally gets a job. It reads 1h/4h features and labels the current market into one of four regimes:

| Regime | Characteristics | Action |
|--------|----------------|--------|
| **Trending** | Strong directional drift, low reversal | Allow directional trades, wider stops |
| **Mean-Reverting** | Range-bound, high reversal probability | Allow counter-trend trades, tight targets |
| **Volatile** | High ATR, erratic moves | **No new trades** — existing positions only |
| **Quiet** | Low volume, tight range | **No new trades** — fees eat everything |

**Rule:** If regime = Volatile or Quiet, the strategy returns `HOLD` immediately. No ML prediction is even consulted. This alone cuts 40–60% of trades.

### Layer 2: 1h Primary Signal (The Direction)
Your existing FreqAI 1h identifier generates a prediction every hour:
- `future_return_1h` > threshold → **LONG** bias
- `future_return_1h` < −threshold → **SHORT** bias
- Otherwise → **NEUTRAL**

This is the **only** timeframe that generates trade direction. It is slow, deliberate, and fee-efficient.

### Layer 3: 5m Entry Precision (The Timing)
When the 1h signal fires, you do **not** market order. Instead:
- Switch to 5m microstructure features (your built-but-untested `micro_features.py`)
- Wait for a 5m pullback **against** the 1h direction
- Place a **maker limit order** at the pullback extreme
- If filled within 3 candles, you enter with positive slippage (better than market)
- If not filled, the setup expires — no trade, no fee

**Example:** 1h says LONG. Price is $63,891. You wait for a 5m dip to $63,820. You place a buy limit at $63,825. If filled, you are already +$66 ahead of the market price. That is your fee buffer.

### Layer 4: LLM Veto (The Sanity Check)
Before any order is submitted, the full context is sent to your Qwen3-8B:

```
Context:
- Regime: Trending (confidence: 0.82)
- 1h prediction: LONG, confidence 0.71, expected return +0.35%
- 5m entry: limit buy at $63,825 (pullback from $63,891)
- Funding rate: +0.01% (longs pay — negative for longs)
- Options skew: 25-delta put/call = 1.12 (slight fear, contrarian bullish)
- Recent trades: Last 3 longs: 2 wins, 1 loss. Current streak: win.

Question: Approve this trade? Return JSON:
{
  "decision": "APPROVE" | "REJECT" | "REDUCE_SIZE",
  "confidence": 0.0-1.0,
  "reason": "string",
  "size_adjustment": 0.0-1.0
}
```

**Gates:**
- LLM confidence < 0.6 → Trade size halved
- LLM decision = REJECT → No trade
- LLM decision = REDUCE_SIZE → Multiply position by `size_adjustment`

This is not shadow mode anymore. This is **trade authority**.

### Layer 5: Self-Learning Feedback Loop (The Evolution)

Every Sunday at 00:00 UTC, the system runs a **strategy audit**:

1. **Model Retraining**
   - Retrain 1h FreqAI model on the last 30 days of data
   - Drop features whose SHAP importance dropped >50% vs. last month
   - Add new features if correlation to residual returns > 0.15

2. **Regime Recalibration**
   - Re-fit KMeans on last 60 days of 1h/4h data
   - Check: did "Trending" regime actually produce positive returns?
   - If a regime's Sharpe < 0 for 2+ weeks, flag it for review

3. **LLM Benchmark Update**
   - Run frozen benchmark (your existing 200 scenarios)
   - If accuracy dropped >5% vs. last month, trigger re-fine-tuning on new data
   - Use your 107k shadow rows as training material

4. **Parameter Evolution**
   - Auto-adjust:
     - `entry_threshold` based on recent win rate
     - `spread_buffer` for limit orders based on fill rate
     - `position_size` based on recent max drawdown
   - Changes logged to `docs/week_X_evolution.md`

## Execution Rules (The Discipline)

### Order Rules
- **Maker-only.** Every entry is a limit order. No market orders. No exceptions.
- **One position per pair.** No pyramiding.
- **Max 2 pairs.** BTC/USDT and ETH/USDT only. Depth = edge.

### Risk Rules
- **Stop loss:** −1.5% per trade (hard)
- **Max drawdown:** −5% daily → halt trading until next day
- **Position size:** 5% of NAV per trade (reduced to 2.5% if LLM says REDUCE_SIZE)
- **Inventory limit:** If net exposure > 15% of NAV in one direction, halt new entries on that side

### Exit Rules
- **Time stop:** Close after 4h if not stopped or target hit (prevents bag-holding)
- **Target:** 1.5× the ATR(14) at entry (asymmetric — let winners run)
- **Trailing stop:** Once +1% in profit, trail at 0.5% below highest price
